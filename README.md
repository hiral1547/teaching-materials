# Minimal Academic Teaching Portfolio

A responsive, minimal one-page academic portfolio using:

- HTML5
- CSS3
- Bootstrap 5.3
- jQuery 3.7
- Bootstrap Icons

## Sections

Only the requested main sections are included:

1. About
2. Materials
   - All
   - Lecture Notes
   - PDF Notes
   - Lab Manuals
   - Images
   - Videos
3. Teaching Philosophy
4. Contact

The hero/header is intentionally kept separate from the navigation sections.

## Design

The previous blue/black palette has been replaced with a warm, academic combination:

- Terracotta accent
- Cream background
- Sand sections
- Soft sage highlights
- Dark charcoal text

The design uses Bootstrap utilities/components wherever possible, with a small custom CSS file for branding, colors, cards, and responsive details.

## Customize

Edit `index.html` to replace:

- Your Name
- Department
- Institution
- Email
- LinkedIn
- Profile details

Put your real files into the matching folders under `materials/`, then update the `materials` array in `assets/app.js`.

For the CV, add `assets/Your-Name-CV.pdf` or change the CV link in `index.html`.

## Run

Open `index.html` directly in a browser, or use any simple local server.
